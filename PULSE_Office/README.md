# PULSE — Virtual Office

A multi-user workplace app with task management, staff accounts, rooms, daily routine, presence, and admin controls.

## Features in this MVP
- Admin/staff sign-in (employee ID or email)
- Admin-created staff accounts and team labels
- Office spaces/rooms created by Admin
- Overview counts for pending, in-progress, completed, aging, and online users
- Task creation, assignment, priority, room, deadline
- Task states: Pending, In Progress, Blocked, Completed
- 5-hour aging indicator for tasks in In Progress
- Personal desk: tasks assigned to you and tasks assigned by you
- Task Room with status and priority filters
- Staff presence selector (Online, Working, Away, Focus)
- Daily routine checklist and End My Day summary
- Socket.IO event broadcasting for task/presence changes
- PostgreSQL on Render, SQLite for local development

## Run locally

1. Python 3.11+ recommended.
2. In this folder:

   ```bash
   python -m venv .venv
   # Windows PowerShell
   .venv\Scripts\Activate.ps1
   # macOS/Linux
   # source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Set a secure admin password before first run:

   **PowerShell**
   ```powershell
   $env:ADMIN_PASSWORD="replace-with-a-strong-password"
   $env:ADMIN_ID="PULSE-ADMIN"
   python app.py
   ```
   **macOS/Linux**
   ```bash
   ADMIN_PASSWORD='replace-with-a-strong-password' ADMIN_ID='PULSE-ADMIN' python app.py
   ```
4. Visit `http://127.0.0.1:5000`.

The first run creates a default Admin account and starter rooms. If `ADMIN_PASSWORD` is not set, the development default is `ChangeMe123!` — **change it before any deployment**.


## Deploy to Render

1. Push this folder to a new GitHub repository named `pulse-office`.
2. In Render, choose **New → Blueprint** and connect the repository.
3. Render reads `render.yaml` and provisions the web service and PostgreSQL database.
4. When prompted, set `ADMIN_PASSWORD` to a strong unique password.
5. Deploy. The `DATABASE_URL` and `SECRET_KEY` are provided/generated by Render.
6. Sign in using employee ID `PULSE-ADMIN` and the password you set.


## Important production notes
- Set a unique, strong `ADMIN_PASSWORD` and keep secrets in Render environment variables, never commit them.
- The starter has task status controls and task-room filtering, but no granular room ACLs, password-reset workflow, audit export, file attachments, or true work-session pause accounting yet.
- The 5-hour indicator is currently elapsed time since the task was marked In Progress; it does not pause when the task is blocked or when a user leaves.
- Presence is broadcast on socket connection and selector changes; this MVP does not yet include robust heartbeat expiry.
- This build uses one Gunicorn worker for Socket.IO consistency. Scale-out requires a Socket.IO message queue (e.g. Redis) and appropriate worker configuration.
